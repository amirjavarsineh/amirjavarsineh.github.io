# Amir Javarsineh — CyberSecurity Engineer Portfolio

> A modern, interactive developer portfolio with a terminal-inspired design, featuring live tools, chatbot, and responsive layout.


## 🌟 Live Demo

[https://amirjavarsineh.ir](https://amirjavarsineh.ir)

## 📌 Overview

This is the personal portfolio website of **Amir Javarsineh** – a CyberSecurity Engineer, Network Engineer, and Web Developer. The site showcases skills, experience, certifications, and a collection of interactive educational tools, all wrapped in a unique terminal / hacker aesthetic.

## ✨ Features

### 🖥️ Core Sections
- **Hero with typewriter effect** – dynamic tagline changes.
- **Interactive Terminal Chatbot** – commands: `help`, `skills`, `contact`, `whoami`, `clear`, plus hacking simulations (`nmap`, `hydra`, `exploit`, etc.)
- **Full‑screen Terminal Mode** – immersive CLI experience.
- **Skills radar chart** (Chart.js) – visual representation of expertise.
- **Professional timeline** – experience & education.
- **Certifications gallery** – with lightbox preview.
- **Contact section** – email and social links.

### 🛠️ Useful Tools (Network & System)
- **Subnet Calculator** – real IP/CIDR calculations.
- **IPv4 ↔ Binary Converter** – bidirectional conversion.
- **Strong Password + Username Generator** – random secure credentials.
- **Unit Converter** – length, weight, temperature, time, speed, volume, area, energy, pressure (accurate formulas).
- **Motivational Quote Generator** – 365 fixed inspiring quotes.
- **Text ↔ Binary Converter** – ASCII 8‑bit conversion.
- **Random Number Generator** – custom range.
- **Base64 Encoder / Decoder**.
- **Password Strength Checker** – realistic entropy‑based crack time estimation.
- **Character / Word / Line Counter**.

### 🎨 Visual & Interactive Enhancements
- **Boot screen** – simulated system startup.
- **Matrix digital clock** – live time & date with matrix style.
- **Particle explosion button** – colorful particles on click.
- **Fully responsive** – works on desktops, tablets, and mobile devices.
- **Smooth scrolling & lazy loading** sections.

### 🔧 Technical Highlights
- Pure HTML5 / CSS3 / JavaScript – no external frontend frameworks.
- Chart.js for radar chart.
- Font Awesome 6 icons.
- No backend required – all tools run client‑side.

## 🛠️ Installation & Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/amirjavarsineh/amirjavarsineh.github.io.git
   cd amirjavarsineh-portfolio
   ```

2. **Open the project**
   - Simply open `index.html` in your browser.
   - Or use a local server (e.g., Live Server in VS Code).

3. **Customize**
   - Update personal information, skills, experience, and certificates in `index.html`.
   - Modify colors in `:root` variables inside `main.css`.
   - Adjust tool constants or add new commands in `main.js`.

## 🧪 Usage Guide

### Interactive Terminal (Hero)
Type commands in the chat‑style terminal:
- `help` – show all commands.
- `skills` – list technical skills.
- `contact` – display contact info.
- `whoami` – about Amir.
- `clear` – clear conversation.
- `nmap <target>` – simulated port scan.
- `hydra <service>` – brute‑force simulation.
- `exploit` – random exploit.
- `reverse-shell` – fake reverse shell.
- `crack <hash>` – hash crack simulation.
- `enum` – system enumeration.
- `pwn` – attack simulation.
- `backdoor`, `persistence`, `root` – educational hack scenarios.

### Full‑screen Terminal Mode
Click **Fullscreen Terminal** – same commands but full‑screen overlay.


### Tools Section
All tools are self‑explanatory. Just fill inputs and click buttons.
